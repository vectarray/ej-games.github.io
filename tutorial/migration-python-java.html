Python -> Java

This is a tutorial that is designed to help you migrate from Python to Java, or just find out the differences.

Intro

Python and Java are vastly different languages, but have the same premise: being able to run on any device, anywhere.

Python is also an interpreted language, whereas Java is sort of compiled as well as interpreted, because the Java Virtual Machine is an interpreter that reads the compiled Java file.

Variables and Datatypes

Java is strong-typed, unlike Python. For example, if you make an int in Java, and then change your mind about what datatype it should be, then tough luck, it's always an int.

If you make an int in Python, for reference, that variable can become whatever you want it to be.

The naming convention for variables and methods is camelType (var myVariable), and for classes, it is PascalCase (class HelloEveryone)

Functions and Classes

This is a function in Java: 
function funkyFunction():
	print("This is funky and swish!")

But, not as shown earlier, this is a class in Java: 
class CoolTerms
{

	swish = "That's very swish!"

	function funkyFunction()
		swish = "I prefer 'funky'"
}

To return a value from a function, you can do this: 
string funkyFunction()
{
	return "I prefer 'funky'"
}
